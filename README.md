# 🚴 鹈鹕的单车之旅

**在线体验：** https://yjj0339.github.io/pelican-journey/

一个全新创作的鹈鹕骑自行车2D动画网页，包含三个时段场景。

## 特性

- 🎨 三个场景：清晨、正午、日落
- 🐦 鹈鹕角色完整动画（IK腿部、翅膀摆动）
- 🚲 自行车物理运动（车轮转动、踏板联动）
- 🌳 视差滚动（云朵、树木、草地多层）
- 📱 点击画布切换场景
- 💯 纯原生技术（HTML + Canvas）

## 技术实现

- Canvas 2D 渲染
- 两段 IK 腿部动画
- 多层视差滚动系统
- 场景状态管理
- 响应式布局
